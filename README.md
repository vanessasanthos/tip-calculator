# 🧮 Python Tip Calculator

## 🇧🇷 Sobre o projeto

Este projeto consiste em uma calculadora de gorjetas desenvolvida em Python. O programa solicita o valor total da conta, a porcentagem de gorjeta desejada e a quantidade de pessoas que irão dividir o pagamento.

Com essas informações, calcula o valor total com a gorjeta incluída e quanto cada pessoa deverá pagar.

## 🇺🇸 About the project

This project is a tip calculator developed using Python. The program asks the user for the total bill, the desired tip percentage, and the number of people splitting the payment.

It calculates the total amount, including the tip, and determines how much each person should pay.

## 🎯 Objetivo | Objective

Praticar lógica de programação e operações matemáticas utilizando Python.

Practice programming logic and mathematical operations using Python.

## ⚙️ Funcionalidades | Features

- Entrada do valor total da conta.
- Escolha da porcentagem de gorjeta (10%, 12% ou 15%).
- Informar a quantidade de pessoas.
- Cálculo automático da gorjeta.
- Divisão do valor total entre os participantes.
- Arredondamento do valor final para duas casas decimais.

## 🛠️ Tecnologias | Technologies

- Python 3

## 📚 Conceitos praticados | Concepts practiced

- Variáveis
- Entrada de dados com `input()`
- Conversão de tipos com `float()` e `int()`
- Operações matemáticas
- Divisão e multiplicação
- Porcentagens
- Função `round()`
- Exibição de resultados com f-strings.

Throughout this project, I practiced mathematical operations, decimal number handling, and data type conversion. I also developed logic to split a bill proportionally among multiple people.
